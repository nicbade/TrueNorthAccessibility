# Figma Make Prompt — TrueNorth Accessibility

Build a professional, clean marketing website for **TrueNorth Accessibility**, an LLC providing digital accessibility consulting (WCAG audits, remediation, training, VPATs, etc.).

## Style
Match the visual style of my portfolio site (nicbade.com):
- **Background:** warm off-white/cream (#F5F3EF-ish), no pure white
- **Headings:** serif font (like Georgia/Lora), large, understated
- **Body text:** clean sans-serif, muted dark gray (not pure black)
- **Accent color:** deep forest green — used for eyebrow labels, buttons, links
- **Buttons:** solid forest green, white text, small rounded corners, no shadow
- **Layout:** generous whitespace, sections separated by thin hairline dividers, left-aligned content, max-width centered container
- **Nav:** simple text logo/wordmark top-left, text links top-right, no background contrast
- **Footer:** minimal — copyright left, links right
- Logo provided — use it in the nav header (top left, replacing text wordmark) and footer

## Pages / Sections
1. **Home**
   - Hero: company name, tagline, one-line value prop, primary CTA ("Book a consultation" or similar)
   - Services overview (3–4 cards): e.g. Accessibility Audits, Remediation, Training, VPAT/Compliance Reports
   - Trust signals: certifications, WCAG/ADA/Section 508 mention, past client logos if any
   - CTA banner near bottom

2. **Services**
   - Detailed breakdown of each service with what's included
   - Pricing/process overview if applicable (or "request a quote")

3. **About**
   - Founder bio / why TrueNorth exists
   - Approach/philosophy on accessibility

4. **Contact**
   - Simple form (name, email, message)
   - Direct email/phone
   - Calendly-style booking link if available
